# Java Fundamentals
c/o Jack Vranicar

## Summary
This repository contains code / resources to get started with Java. This material is meant for programmers with no programming experience!

## Use
1. Clone the repository to your computer.
2. Using VSCode, open InitialTest.java
3. Try running this file by pressing the 'play' button at the top right of the window
4. A number of pop-ups will show if you haven't installed Java. Follow all the pop-up instructions to install Java *IF asked if you want to use a default version, click yes*
5. It will take a while to run the first time you try; be patient. You may need to try and run it twice.
6. The output terminal should have a message if you've installed it properly.
7. I recommend changing the terminal output:
   a.  (Ctrl + , on Windows/Linux or Cmd + , on macOS).
   b. Search for java.debug.settings.console in the top search bar.
   c. Change the dropdown setting from integratedTerminal to internalConsole
